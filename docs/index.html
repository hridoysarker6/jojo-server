JOJO Server

A free local web server for Windows

Run Nginx or Apache with PHP, MySQL, PostgreSQL, Redis and Mailpit on your own PC. Create Laravel and WordPress sites in one click. A free, open-source Laragon and XAMPP alternative for PHP developers.

Download for Windows View the source on GitHub

64-bit Windows 10 and 11 · MIT license · no account, no ads. The installer is not code-signed yet, so Windows may say "Unknown publisher": choose More info, then Run anyway.

Everything a PHP project needs

Nginx or Apache

Pick the web server you like. Apache reads .htaccess. Both serve every site, with HTTPS and per-site PHP.

PHP, any version

Install several PHP versions and give each site its own. Manage extensions such as Redis, Xdebug and APCu, and PHP settings, from the app.

Databases and cache

MySQL, PostgreSQL and Redis with a built-in Redis browser, plus DbGate and Adminer for your data.

One-click projects

New Laravel (with database, mail and npm set up), WordPress or Symfony sites, ready to open in the browser.

Local domains and HTTPS

Every folder becomes name.test. Turn on wildcard domains for sub-domains, and trusted HTTPS with one click.

Mail and logs

Mailpit catches every email your app sends. A log viewer shows PHP, web server and Laravel logs.

Terminal and tools

A terminal per project with that project's PHP, Composer and Node.js on the path, and background workers for queues and schedulers.

Share a site

Give a client a temporary public link to your local site through a free Cloudflare tunnel.

Get started in three steps

  1. Download and run the installer. Choose where your files should live (drive D: is suggested when you have one).
  2. On the Dashboard, click Install recommended stack, then Start All.
  3. In Sites, create a project and open http://yourproject.test.

Questions

Is JOJO Server free?

Yes. It is open source under the MIT license. There is no paid version and nothing is locked.

Which versions of Windows does it support?

64-bit Windows 10 and 11. It has been tested on Windows 10.

Can I use Apache instead of Nginx?

Yes. Install both and choose one in Settings. Only one runs at a time, on the same port.

Can different projects use different PHP versions?

Yes. Every site has its own PHP version, and its Terminal button uses the same PHP, Composer and Node.js.

Do I need administrator rights?

Not for installing or running the servers. A few optional features ask for one Windows prompt: editing the hosts file, wildcard domains and trusting the local HTTPS certificate. The app lists exactly what it changes in its README.

Is it a Laragon or XAMPP alternative?

It covers similar ground for PHP developers on Windows. It is an independent project and is not affiliated with Laragon or XAMPP.
